Tóm Tắt Quy Tắc Thiết Kế & Bộ 3 Mã Nguồn Mở Sạch Bản Quyền B2B

Đảm bảo tiêu chí cứng của cAI: 100% bán thương mại / white-label được (chỉ dùng Apache-2.0 & MIT), tách rạch ròi giữa Code — Config — Data — LLM.

Apache-2.0 · Fork mỏng

1. Rakazo → Giao diện & Nền B2B

Tiết kiệm nhiều tháng build phần nền doanh nghiệp:

  • Multi-tenant `Org → Space → Domain` với PostgreSQL RLS.
  • SCIM 2.0, SpaceKey, Credential Vault (Zero-Exposure), Billing.
  • Tuyệt đối KHÔNG dùng: nút Always Allow, chế độ Auto của chủ bot, hay chat để làm lõi quy trình.
MIT · Lõi mới (Note 04)

2. Temporal + Postgres + CEL → Lõi Hồ Sơ

Trái tim giúp cAI vượt xa chatbot chiều rộng:

  • Case Store: lưu trạng thái hồ sơ độc lập với bộ nhớ bot.
  • Temporal: chạy `process/*.yaml` bền vững, Timer SLA, Signal duyệt.
  • Authority Matrix (CEL) + Stage Hooks: SoD, leo thang, Guard nghiệp vụ không đi vòng được.
MIT · Sidecar tích hợp

3. Obot → Cổng AI & Scale `n` Domain

Giải quyết bài toán hàng trăm tool & kiểm soát tập trung:

  • vMCP + Dynamic Tool Search: chống tràn context ở `n` phòng ban.
  • OpenAPI → MCP: bọc nhanh ERP, ATS, LMS, MISA, Bravo.
  • Unified Guardrails (Chốt chặn #1): lọc PII, Secrets, an toàn trẻ em, Prompt Injection.

Nguyên tắc vàng: Đừng dồn mọi thứ vào Prompt (5 Lớp sau Agent Card)

Power User thấy gì (Agent Card) Hệ thống biên dịch xuống lớp nào? Ai được sửa & Ràng buộc
1. Vai trò & Luật cấm ("không bao giờ...", ngưỡng tiền) Code / Bảng luật có Unit Test (không để trong prompt!) Power User sửa trên Bảng Luật cứng (kiểu Excel) → chạy test tự động.
2. Kiến thức (Knowledge) Dữ liệu nghiệp vụ (mẫu JD, rubric, chính sách) Chủ quy trình / Admin cập nhật mà không cần sửa code hay prompt.
3. Kỹ năng phán đoán (Skills) SKILL.md + Bộ Eval kiểm chứng Muốn publish lên cấp phòng ban bắt buộc vượt ngưỡng Eval.
4. Công cụ (Tools / Apps) vMCP Profile (Obot) Chỉ được bật/tắt trong danh sách tool mà IT/Admin đã duyệt cho phòng ban.
5. Duyệt & Tự chủ (Approvals) process/*.yaml + Authority Matrix (CEL) + Thang 0–4 Chặn trần bởi Policy tổ chức; chi tiền / offer / hợp đồng luôn dừng ở Bậc 2.

Tuần 1–2 Dựng Rakazo fork mỏng + Obot (LLM GW & vMCP ngay từ đầu) + Case Store + Temporal + Authority Matrix tối thiểu + Guard nội dung. Khung 5 lớp chạy thông suốt, sạch bản quyền 100%.
Tuần 3–8 Xây 2 Domain Pack đầu tiên (Tài chính AP & Tuyển dụng) tách đủ 5 lớp; chuyên gia nghiệp vụ viết Eval từ dữ liệu lịch sử trước; bật Guard nghiệp vụ từ sprint đầu. Pass Eval trên Staging với dữ liệu tổng hợp + đầy đủ Audit & HITL.
Tuần 9–12 Pilot tại 2 P&L (bắt đầu từ Bậc 1 chạy bóng), đo adoption & KPI thật; demo Power User tự dựng quy trình thứ 3 (Hoàn ứng) từ SOP + lịch sử không cần sprint code. Chứng minh Moat của cAI để chốt nghiệm thu & thương mại hóa B2B.
